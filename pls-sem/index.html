Apa itu PLS-SEM?

PLS-SEM (Partial Least Squares Structural Equation Modeling) adalah teknik multivariat generasi kedua yang menggabungkan analisis jalur dengan model pengukuran. PLS-SEM memaksimalkan varian yang dijelaskan (R²) pada variabel endogen — berbeda dari CB-SEM yang meminimalkan perbedaan kovarians.

Konteks Studi Kasus (Digunakan Sepanjang Panduan Ini)

Model Reputasi Perusahaan (Hair et al., 2016). Konstruk formatif eksogen: ATTR (Attractiveness), CSOR (CSR), PERF (Performance), QUAL (Quality). Konstruk reflektif endogen: COMP (Competence), LIKE (Likeability), CUSA (Customer Satisfaction), CUSL (Customer Loyalty). n = 344 responden, operator jaringan seluler di Jerman.

Urutan evaluasi wajib: Outer model (Stage 5) harus selesai dan valid sebelum inner model (Stage 6) boleh diinterpretasikan. Ini adalah prinsip fundamental PLS-SEM.
1
Fase 1 — Persiapan
Spesifikasi Model

Tentukan: (1) konstruk laten beserta indikatornya, (2) jenis pengukuran — reflektif atau formatif, (3) arah hubungan antar konstruk berdasarkan teori.

Reflektif
Panah: konstruk → indikator. Indikator saling berkorelasi. Contoh: skala Likert kepuasan. Perubahan konstruk mengubah semua indikator.
Formatif
Panah: indikator → konstruk. Indikator tidak harus berkorelasi. Contoh: indeks SES. Menghapus satu indikator mengubah makna konstruk.
Cara menentukan reflektif vs. formatif: Tanya — jika satu indikator dihapus, apakah makna konstruk berubah? Jika ya → formatif. Apakah indikator bisa saling menggantikan? Jika ya → reflektif. Gunakan Confirmatory Tetrad Analysis (CTA-PLS) untuk uji empiris jika ragu.

  • Periksa cross-loading: jika loading pada konstruk lain hampir setara, itu sinyal item bermasalah secara konseptual
  • Tinjau wording item: ambiguitas pertanyaan sering menjadi penyebab loading rendah

AVE mengukur rata-rata varian yang ditangkap konstruk dari indikatornya dibandingkan varian error. AVE = Σ(λ²) / [Σ(λ²) + Σ(1−λ²)].

Fase 2 — Outer Model Reflektif (Stage 5a)
Discriminant Validity

Discriminant validity memastikan setiap konstruk berbeda secara empiris dari konstruk lainnya.

1 — Cross-Loadings

Setiap indikator harus memiliki loading lebih tinggi pada konstruknya sendiri daripada pada konstruk lain manapun.

Contoh Kasus

Indikator cusl_2: loading pada CUSL = 0.917. Cross-loading pada COMP = 0.389, LIKE = 0.482, CUSA = 0.551. Semuanya jauh lebih kecil → Terpenuhi ✓

2 — Fornell-Larcker Criterion

√AVE setiap konstruk harus lebih besar dari korelasinya dengan konstruk lain manapun.

√AVE_COMP = √0.681 = 0.825 Korelasi COMP–CUSL = 0.567 < 0.825 ✓ Korelasi COMP–LIKE = 0.630 < 0.825 ✓ Korelasi COMP–CUSA = 0.576 < 0.825 ✓
Fornell-Larcker memiliki keterbatasan saat loading antar konstruk hanya sedikit berbeda. Gunakan HTMT sebagai konfirmasi utama.
3 — HTMT (Direkomendasikan oleh Hair et al.)

Rasio rata-rata korelasi heterotraits terhadap rata-rata korelasi monotraits. Lebih sensitif dari dua metode di atas.

< 0.85
Konstruk konseptual berbeda jelas
✓ Threshold konservatif
< 0.90
Konstruk konseptual mirip
⚠ Threshold lebih longgar
≥ 0.90

✗ Discriminant validity bermasalah

Contoh Narasi — Discriminant Validity Terpenuhi
"Discriminant validity dievaluasi menggunakan tiga pendekatan komplementer. Pertama, pemeriksaan cross-loading menunjukkan bahwa setiap indikator memiliki loading tertinggi pada konstruknya sendiri dibandingkan konstruk lain — misalnya, cusl_2 memiliki loading 0.917 pada CUSL namun hanya 0.551 pada CUSA. Kedua, kriteria Fornell-Larcker terpenuhi karena akar kuadrat AVE setiap konstruk (berkisar 0.825–0.917) melampaui korelasi tertinggi dengan konstruk lain. Ketiga, nilai HTMT untuk semua pasangan konstruk berada di bawah 0.85, dengan confidence interval BCa 95% yang seluruhnya tidak mencakup nilai 1. Berdasarkan ketiga kriteria tersebut, discriminant validity terkonfirmasi secara meyakinkan untuk seluruh konstruk reflektif dalam model."
⚠ Alternatif jika HTMT ≥ 0.85 atau CI Mencakup 1
  • Tinjau ulang definisi konstruk: dua konstruk mungkin terlalu overlap konseptual — pertimbangkan penggabungan
  • Hapus indikator cross-loading tinggi: indikator yang turut mengukur konstruk lain menjadi sumber masalah
  • Pertimbangkan higher-order construct: jika dua konstruk berkorelasi tinggi karena keduanya adalah dimensi dari satu konstruk lebih luas
  • Tambahkan indikator lebih spesifik untuk memperkuat diferensiasi antar konstruk
Quality Criteria → Discriminant Validity → HTMT / Cross Loadings / Fornell-Larcker

Fase 3 — Outer Model Formatif (Stage 5b)
Kolinearitas Indikator Formatif — VIF

Kolinearitas tinggi antar indikator formatif membiaskan outer weights dan bisa membalik tanda (sign reversal). VIF = 1 / (1 − R²ₓ), di mana R²ₓ adalah varian indikator x yang dijelaskan indikator lain.

VIF < 5
Toleransi > 0.20
✓ Kolinearitas tidak kritis
VIF ≥ 5
Toleransi ≤ 0.20
✗ Kolinearitas kritis — tindakan diperlukan
Contoh Kasus — VIF Indikator Formatif (QUAL)
IndikatorVIFStatus
qual_11.924< 5 ✓
qual_32.269< 5 ✓
qual_81.532< 5 ✓

Semua VIF di bawah 5 → tidak ada masalah kolinearitas pada indikator formatif model ini.

Contoh Narasi — VIF Formatif Terpenuhi
"Untuk memastikan tidak terdapat masalah kolinearitas antar indikator formatif, dihitung nilai Variance Inflation Factor (VIF) untuk setiap indikator dalam masing-masing konstruk formatif. Hasil menunjukkan bahwa seluruh nilai VIF berada di bawah batas kritis 5 — nilai tertinggi ditemukan pada qual_3 sebesar 2.269. Oleh karena itu, tidak ada indikasi kolinearitas yang dapat mengganggu estimasi outer weights, dan evaluasi dapat dilanjutkan ke tahap berikutnya."
Perhatian: Bivariate correlation > 0.60 antara dua indikator formatif sudah bisa menjadi sinyal potensi kolinearitas meski VIF belum mencapai 5. Selalu periksa correlation matrix sebagai langkah awal.
⚠ Alternatif jika VIF ≥ 5
  • Hapus salah satu indikator kolinear — pilih yang paling dapat diwakilkan oleh indikator lain, pastikan content validity tetap terjaga
  • Gabungkan menjadi satu indeks komposit — rata-ratakan atau beri bobot indikator bermasalah menjadi satu variabel baru
  • Buat higher-order formative construct — kelompokkan indikator kolinear ke sub-konstruk tersendiri lalu jadikan indikator formatif tingkat atas

Efek Langsung, Tidak Langsung, dan Total
Efek tidak langsung (Y1→Y2→Y3) = p₁₂ × p₂₃ = 0.80 × 0.50 = 0.40 Efek langsung (Y1→Y3) = p₁₃ = 0.20 Total effect (Y1→Y3) = 0.20 + 0.40 = 0.60

Total effects berguna melihat pengaruh kumulatif melalui mediator. Selalu uji signifikansinya via bootstrapping secara terpisah.

Contoh Narasi — Path Signifikan & Bermakna
"Hasil pengujian hipotesis menggunakan bootstrapping (5.000 sampel, BCa, two-tailed, α = 0.05) menunjukkan bahwa hubungan antara Customer Satisfaction (CUSA) dan Customer Loyalty (CUSL) adalah signifikan (β = 0.505, t = 12.329, p < 0.001). Bootstrap confidence interval BCa 95% [0.428, 0.580] tidak mencakup angka 0, mengkonfirmasi signifikansi pada tingkat 5%. Temuan ini mengindikasikan bahwa setiap peningkatan satu unit dalam kepuasan pelanggan dikaitkan dengan peningkatan loyalitas sebesar 0.505 unit, dengan asumsi variabel lain tetap konstan. Dengan demikian, Hipotesis 5 didukung oleh data."
Contoh Narasi — Path Tidak Signifikan (Tetapi Ada Efek Tidak Langsung)
"Hipotesis yang menyatakan bahwa Competence (COMP) berpengaruh langsung terhadap Customer Loyalty (CUSL) tidak terdukung (β = 0.006, t = 0.100, p = 0.920). Confidence interval BCa 95% mencakup nilai nol [−0.111, 0.113], mengkonfirmasi ketidaksignifikanan. Hasil ini mengindikasikan bahwa kompetensi yang dipersepsikan tidak memberikan dampak langsung yang berarti terhadap loyalitas pelanggan. Namun demikian, total effect COMP terhadap CUSL melalui CUSA sebagai mediator tetap signifikan (β = 0.079, p = 0.027), menunjukkan bahwa pengaruh kompetensi terhadap loyalitas bersifat tidak langsung, tersalurkan sepenuhnya melalui kepuasan pelanggan. Dengan demikian, hipotesis tentang pengaruh langsung COMP → CUSL tidak didukung, namun relevansi COMP dalam model tetap terkonfirmasi melalui jalur mediasi."
⚠ Alternatif jika Path Tidak Signifikan
  • Jangan langsung hapus hubungan: periksa apakah efeknya tersalurkan melalui mediator (cek total effects)
  • Pertimbangkan re-spesifikasi teoritis jika hipotesis memang tidak terdukung secara konsisten
  • Cek ukuran sampel: sampel kecil meningkatkan SE → path yang mungkin signifikan di populasi terlihat tidak signifikan
  • Pertimbangkan one-tailed test jika hipotesis memiliki arah yang jelas dan didukung teori kuat

Coefficient of Determination — R² & R² Adjusted

R² mengukur proporsi varian konstruk endogen yang dijelaskan oleh semua konstruk eksogen yang terhubung (in-sample predictive power).

≥ 0.75
Substantial
✓ Prediksi kuat
≥ 0.50

⚠ Prediksi sedang
≥ 0.25
Weak
⚠ Prediksi lemah
< 0.25

✗ Prediksi sangat rendah
Konteks menentukan: R² = 0.20 dianggap tinggi dalam consumer behavior. Dalam studi kepuasan pelanggan, diharapkan R² ≥ 0.75. Jangan gunakan threshold ini secara kaku lintas disiplin.
R² Adjusted — Untuk Perbandingan Model
R²adj = 1 − (1 − R²) × (n − 1) / (n − k − 1) n = jumlah sampel valid k = jumlah konstruk eksogen prediktor

Gunakan R² adjusted saat membandingkan dua model dengan jumlah prediktor atau sampel berbeda. R² biasa selalu naik jika prediktor ditambahkan — R² adjusted mengkoreksi bias ini.

Contoh Narasi — R² Terpenuhi
"Kemampuan prediktif model struktural dievaluasi menggunakan koefisien determinasi (R²). Hasil menunjukkan bahwa COMP memiliki R² sebesar 0.631, artinya keempat konstruk formatif eksogen (ATTR, CSOR, PERF, QUAL) mampu menjelaskan sekitar 63.1% varian dalam persepsi kompetensi perusahaan. LIKE dan CUSL masing-masing memperoleh R² sebesar 0.558 dan 0.562, tergolong moderate. Konstruk CUSA memperoleh R² sebesar 0.292 yang tergolong lemah, mengindikasikan adanya faktor penjelas tambahan di luar model. Secara keseluruhan, nilai R² berada dalam rentang yang dapat diterima untuk penelitian di bidang pemasaran jasa (Hair et al., 2016)."
Contoh Narasi — R² Rendah (Bagaimana Mendiskusikannya)
"Konstruk CUSA memperoleh R² sebesar 0.292, artinya hanya 29.2% varian kepuasan pelanggan yang dapat dijelaskan oleh COMP dan LIKE dalam model ini. Meskipun nilai ini tergolong lemah menurut panduan Hair et al. (2016), hal ini tidak serta-merta berarti model tidak valid. Kepuasan pelanggan dalam industri telekomunikasi dipengaruhi oleh banyak faktor kontekstual — seperti kualitas jaringan, harga, dan pengalaman layanan — yang tidak dimasukkan dalam model reputasi ini. Keterbatasan ini membuka agenda penelitian lanjutan yang dapat mengintegrasikan variabel-variabel tersebut untuk meningkatkan daya prediksi model."
⚠ Alternatif jika R² Rendah
  • Tambahkan konstruk prediktor relevan secara teoritis (bukan hanya untuk naikkan angka)
  • Tinjau ulang indikator: loading rendah memperlemah konstruk dan menurunkan R²
  • Pertimbangkan variabel moderator: mungkin ada kondisi batas (boundary condition) yang membuat hubungan lebih kuat pada kelompok tertentu
  • Akui secara eksplisit: R² rendah berarti ada faktor lain di luar model — ini lazim dan bisa menjadi agenda penelitian berikutnya

f² mengukur kontribusi substantif satu konstruk eksogen terhadap R². Penting karena path yang signifikan belum tentu penting secara substantif — terutama dengan sampel besar.

⚠ Kontribusi berarti
≥ 0.02

⚠ Kontribusi ada tapi kecil

6e
Fase 4 — Inner Model / Struktural (Stage 6)
Predictive Relevance Q² — Blindfolding

Q² mengukur kemampuan model memprediksi data yang tidak digunakan saat estimasi (out-of-sample predictive power). Berbeda dari R² yang hanya mengukur in-sample fit. Diterapkan hanya pada konstruk endogen reflektif.

Q² > 0
Ada predictive relevance
✓ Model mampu memprediksi
Q² ≤ 0
Tidak ada predictive relevance
✗ Model gagal memprediksi
Cara Menentukan Omission Distance (D)
Syarat wajib: (n / D) BUKAN bilangan bulat Range direkomendasikan: D = 5 hingga 10 Rumus Q²: Q² = 1 − (SSE / SSO) SSE = sum of squared prediction errors SSO = sum of squared observations
Gunakan cross-validated redundancy (bukan communality) karena mencakup informasi structural model dalam prediksi — lebih sesuai orientasi PLS-SEM.
Contoh Kasus — Q² Model Reputasi (n = 344, D = 7, 344/7 = 49.14 ✓)

Contoh Narasi — Q² Terpenuhi
"Relevansi prediktif model dievaluasi menggunakan prosedur blindfolding dengan omission distance D = 7 (344 / 7 = 49.14, bukan bilangan bulat, memenuhi syarat). Berdasarkan tabel Construct Cross-validated Redundancy, nilai Q² seluruh konstruk endogen reflektif berada di atas nol: COMP dan CUSL masing-masing sebesar 0.415, LIKE sebesar 0.406, dan CUSA sebesar 0.280. Sesuai kriteria Hair et al. (2016), Q² > 0 mengkonfirmasi bahwa model memiliki relevansi prediktif yang memadai. Artinya, model tidak hanya mampu menjelaskan data yang digunakan untuk estimasi (in-sample), tetapi juga mampu memprediksi data yang dikecualikan dari proses tersebut (out-of-sample). Dengan demikian, kemampuan prediktif model secara keseluruhan terkonfirmasi."
⚠ Alternatif jika Q² ≤ 0
  • Tinjau kembali spesifikasi model: mungkin ada konstruk penting yang terlewat dari model
  • Periksa kualitas data: data sangat noisy atau tidak konsisten menurunkan Q²
  • Coba omission distance berbeda: hasil Q² sedikit bervariasi tergantung D yang dipilih
  • Pertimbangkan model yang lebih parsimonious: terlalu banyak konstruk lemah bisa menurunkan Q²

Checklist Pelaporan PLS-SEM
Outer Model Reflektif
  • Outer loading semua indikator dilaporkan dan ≥ 0.70 (atau justifikasi retensi jika 0.40–0.70)
  • Composite Reliability (CR) dilaporkan untuk setiap konstruk (target: 0.70–0.90)
  • Cronbach's Alpha dilaporkan untuk setiap konstruk (target: 0.70–0.90)
  • AVE dilaporkan untuk setiap konstruk (≥ 0.50)
  • Cross-loadings diperiksa (loading tertinggi pada konstruknya sendiri)
  • Fornell-Larcker criterion diperiksa (√AVE > korelasi tertinggi)
  • HTMT dilaporkan untuk semua pasang konstruk (< 0.85 atau < 0.90)
  • BCa confidence interval HTMT diuji (tidak mencakup nilai 1)
Outer Model Formatif (jika ada)
  • Redundancy analysis dilakukan dan path ≥ 0.70
  • VIF setiap indikator formatif dilaporkan (< 5)
  • Outer weights dan outer loadings dilaporkan dengan t-value dan p-value (bootstrapping 5.000 sampel)
  • Keputusan retensi atau hapus indikator dijustifikasi secara teoritis
Inner Model / Struktural
  • VIF inner model diperiksa untuk semua set prediktor (< 5)
  • Path coefficients dilaporkan dengan t-value atau p-value (bootstrapping 5.000 sampel)
  • BCa confidence interval dilaporkan untuk setiap path
  • Total effects dihitung dan diuji signifikansinya via bootstrapping
  • R² setiap konstruk endogen dilaporkan dan diinterpretasikan
  • R² adjusted dilaporkan (terutama saat membandingkan model)
  • f² effect size dihitung dan dilaporkan (0.02 / 0.15 / 0.35 = kecil / sedang / besar)
  • Q² via blindfolding dilaporkan untuk setiap konstruk endogen reflektif (> 0)
  • Omission distance D valid: n/D bukan bilangan bulat, D = 5–10
  • q² effect size dihitung manual dan dilaporkan
