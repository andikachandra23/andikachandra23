💡
Apa Itu Microsoft Excel?
  • Excel adalah program pengolah angka (spreadsheet) buatan Microsoft — bagian dari paket Microsoft Office.
  • Digunakan di hampir semua bidang pekerjaan: keuangan, bisnis, administrasi, pendidikan, riset, dan lainnya.
  • File Excel modern berekstensi .xlsx. Versi lama menggunakan .xls.
  • Keunggulan utama: mampu menghitung ribuan data secara otomatis hanya dengan satu rumus.
  • Tersedia di Microsoft Office (lisensi berbayar) dan Microsoft 365 (berlangganan online).
💡

Analogi sederhana: Bayangkan Excel seperti buku catatan kotak-kotak raksasa. Setiap kotak bisa diisi angka, teks, atau rumus yang menghitung otomatis — seperti kalkulator tak terbatas!

🖥️
Komponen Antarmuka Excel
  • Title Bar — Bagian paling atas, menampilkan nama file yang sedang dibuka (contoh: "Buku1 - Excel").
  • Ribbon — Kumpulan menu perintah di bagian atas, dikelompokkan dalam tab: Home, Insert, Formulas, Data, Review, View.
  • Quick Access Toolbar — Di pojok kiri atas, tombol cepat untuk Save, Undo, Redo.
  • Name Box — Kotak di kiri atas area kerja, menampilkan alamat sel aktif (misal: A1, C5).
  • Formula Bar — Di bawah Ribbon, tempat melihat dan mengedit isi atau rumus sel.
  • Lembar Kerja (Worksheet) — Area kotak-kotak utama tempat Anda bekerja.
  • Sheet Tab — Tab di bagian bawah layar untuk berpindah antar lembar kerja (Sheet1, Sheet2…).
  • Scroll Bar — Bilah geser horizontal dan vertikal untuk menavigasi lembar kerja.
  • Status Bar — Di bawah layar, menampilkan info cepat (SUM, AVERAGE, COUNT) saat sel dipilih.
📐
Memahami Sel, Baris, Kolom, dan Range
  • Kolom — Ditandai huruf (A, B, C … Z, AA, AB …) berjalan secara vertikal. Total 16.384 kolom.
  • Baris — Ditandai angka (1, 2, 3 … 1.048.576) berjalan secara horizontal.
  • Sel (Cell) — Pertemuan antara satu kolom dan satu baris. Contoh: B3 = kolom B, baris ke-3.
  • Sel Aktif — Sel yang sedang dipilih, ditandai batas berwarna hijau tebal.
  • Range — Kumpulan beberapa sel. Contoh: A1:C5 = semua sel dari A1 sampai C5 (15 sel total).

Membuka, Menyimpan & Menutup File
1
Buka Excel baru: Klik Start → ketik "Excel" → Enter → pilih Blank Workbook.
2
Simpan (Save): Tekan Ctrl + S → pilih lokasi folder → ketik nama file → klik Save.
3
Buka file lama: Tekan Ctrl + O → Browse → cari file → double-click atau klik Open.
4
Save As (simpan salinan): Tekan F12 → ganti nama atau lokasi → klik Save.
5
Tutup file: Tekan Ctrl + W. Jika ada perubahan belum tersimpan, Excel akan bertanya.
⚠️

Kebiasaan baik: Simpan pekerjaan setiap 5–10 menit dengan Ctrl+S. Beri nama file yang deskriptif — misalnya "Nilai_Mahasiswa_Genap_2025", bukan "Book1" atau "file_baru"!

  • Data Teks (nama, alamat) → otomatis rata kiri. Data Angka → otomatis rata kanan.
  • Data Tanggal → ketik format 1/1/2025 atau 1-Jan-2025. Excel mengenali sebagai tanggal.
  • Mengedit isi sel: double-click pada sel ATAU klik sel lalu tekan F2.
  • Menghapus isi sel: klik sel → tekan Delete.
  • Batalkan perubahan terakhir: tekan Ctrl + Z (bisa berkali-kali).
  • AutoComplete: Excel menebak teks dari entri sebelumnya. Tekan Enter untuk menerima, Esc untuk menolak.

Operator Aritmatika — Aturan Dasar
  • Setiap rumus Excel wajib diawali tanda sama dengan ( = ). Tanpanya, Excel menganggap sebagai teks biasa!
  • + (tambah): =A1+B1    - (kurang): =A1-B1    * (kali): =A1*B1
  • / (bagi): =A1/B1    ^ (pangkat): =A1^2 (kuadrat)    % (persen): =A1*20%
Contoh Rumus Sederhana
=5+3 → 8 =A2*B2 → mengalikan isi A2 dan B2 =(A1+B1)/2 → rata-rata manual A1 dan B1 =2^10 → 1024 (2 pangkat 10)
⚠️

Urutan prioritas (seperti matematika): ^ dulu, lalu */ , baru +-. Gunakan kurung ( ) untuk mengubah urutan! Contoh: =2+3*4 → 14. Sedangkan =(2+3)*4 → 20.

AutoFill — Salin Rumus Otomatis
1
Ketik rumus di sel pertama. Contoh: =B2+C2 di sel D2.
2
Klik sel D2 → arahkan kursor ke pojok kanan bawah sel. Kursor berubah jadi tanda + hitam kecil (Fill Handle).
3

4

💡

AutoFill juga untuk urutan data! Ketik "Senin" → AutoFill → Excel lanjutkan "Selasa, Rabu, …". Ketik 1 dan 2 di dua sel → pilih keduanya → AutoFill → menghasilkan 3, 4, 5, dst.

Referensi Absolut vs Relatif
  • Referensi Relatif (A1) — berubah saat rumus disalin. Ini adalah mode default.
  • Referensi Absolut ($A$1) — TIDAK berubah saat disalin. $ mengunci kolom DAN baris.
  • Campuran: $A1 (kolom dikunci, baris berubah) atau A$1 (baris dikunci, kolom berubah).
  • Tekan F4 saat mengedit rumus untuk berganti: A1 → $A$1 → A$1 → $A1 → A1.
Contoh — Hitung Diskon Semua Produk
Harga diskon: =B2*(1-$D$1) $D$1 = sel persentase diskon (misal 20%) Saat AutoFill ke bawah, B2 berubah → B3, B4, … tapi $D$1 tetap!
💰
Format Angka: Mata Uang, Persen, Desimal
  • Pilih sel/range → tekan Ctrl+1 untuk buka dialog Format Cells → tab Number.
  • Number: angka umum dengan pemisah ribuan dan desimal (misal: 1.234,56)
  • Currency / Accounting: tampilkan simbol mata uang (Rp, $). Accounting lebih rapi untuk laporan keuangan.
  • Percentage: otomatis kalikan 100 dan tambah tanda %. Angka 0,75 tampil sebagai 75%.
  • Date: format tanggal sesuai pilihan (dd/mm/yyyy, dd mmmm yyyy, dll.)
⌨️

Shortcut cepat format: Ctrl+Shift+1 = Number | Ctrl+Shift+4 = Currency | Ctrl+Shift+5 = Percentage.

Menggabungkan Teks (Concatenate)
  • Operator & — cara paling mudah: =A1&" "&B1 menggabungkan A1, spasi, dan B1.

  • TEXTJOIN() — fungsi modern: =TEXTJOIN(", ";TRUE;A1:C1) — berguna untuk range banyak sel.
  • Selalu tambahkan spasi atau pemisah di antara teks: &" "& atau &", "&
Contoh Kasus — Buat Alamat Lengkap

Pertemuan 4: Fungsi Logika: IF, AND, OR, COUNTIF

Mahasiswa mampu membuat keputusan otomatis dan menghitung data bersyarat

⏱ 100 menit 🎯 Menengah 📁 Fungsi Logika
🎯 Tujuan Pembelajaran

  • Mengombinasikan IF dengan AND dan OR untuk kondisi ganda
  • Menggunakan COUNTIF dan COUNTIFS untuk menghitung data bersyarat
  • Menggunakan SUMIF dan SUMIFS untuk menjumlahkan data bersyarat
🔀
Fungsi IF — Logika Bercabang
  • IF membuat keputusan otomatis: "jika kondisi ini benar, tampilkan X; jika tidak, tampilkan Y".
  • Struktur: =IF(kondisi; nilai_jika_benar; nilai_jika_salah)
  • Operator perbandingan: = < > <= >= <> (tidak sama dengan)
Contoh IF Tunggal
=IF(B2>=75;"LULUS";"TIDAK LULUS") → Jika nilai ≥ 75 tampil "LULUS", selain itu "TIDAK LULUS" =IF(C2="Laki-laki";"Bapak";"Ibu") → Sapa berdasarkan jenis kelamin =IF(D2>0;D2*0.1;0) → Hitung komisi 10% hanya jika penjualan > 0
🪆
IF Bersarang & IFS — Lebih dari 2 Kemungkinan
  • Jika ada lebih dari 2 kemungkinan, masukkan IF di dalam IF — disebut Nested IF.
  • =IFS() adalah alternatif modern: lebih mudah dibaca dari nested IF.
  • IFS: =IFS(kondisi1;hasil1; kondisi2;hasil2; … ;TRUE;hasil_default)
Contoh Grade Nilai (Nested IF vs IFS)
Nested IF: =IF(B2>=85;"A";IF(B2>=75;"B";IF(B2>=65;"C";IF(B2>=55;"D";"E")))) Menggunakan IFS (lebih rapi): =IFS(B2>=85;"A";B2>=75;"B";B2>=65;"C";B2>=55;"D";TRUE;"E")

OR

COUNTIF, SUMIF & Variannya
COUNTIF
=COUNTIF(range;kriteria)

COUNTIFS

Hitung sel yang memenuhi BEBERAPA kriteria

Latihan Praktik
  • Buka file Pertemuan 2 (tabel nilai mahasiswa)
  • Tambah kolom "Status": LULUS jika Nilai Akhir ≥ 70, TIDAK LULUS jika < 70 — pakai IF
  • Tambah kolom "Grade": A(≥85), B(≥75), C(≥65), D(≥55), E(<55) — pakai IFS
  • Di bawah tabel: hitung Jumlah LULUS dan Jumlah TIDAK LULUS dengan COUNTIF

Pertemuan 6: VLOOKUP, HLOOKUP & Pencarian Data

Mahasiswa mampu mencari dan mencocokkan data antar tabel menggunakan fungsi Lookup

⏱ 100 menit 🎯 Menengah 📁 Pencarian Data
🎯 Tujuan Pembelajaran
  • Menggunakan VLOOKUP untuk mencari data secara vertikal antar tabel
  • Memahami perbedaan VLOOKUP dan HLOOKUP
  • Menggunakan INDEX & MATCH sebagai alternatif VLOOKUP yang lebih fleksibel
  • Mereferensikan data dari sheet yang berbeda
🔍
VLOOKUP — Pencarian Data Vertikal
  • VLOOKUP = Vertical Lookup — mencari nilai di kolom pertama tabel, lalu mengambil data dari kolom lain di baris yang sama.
  • Struktur: =VLOOKUP(nilai_cari; tabel_referensi; nomor_kolom; [0/FALSE])
  • Parameter 1: nilai yang dicari (kode produk, NIM, nama)
  • Parameter 2: range tabel referensi — kolom PERTAMA harus berisi nilai yang dicari. SELALU gunakan $!
  • Parameter 3: nomor kolom yang ingin diambil datanya (dihitung dari kolom pertama tabel referensi)
  • Parameter 4: selalu isi 0 atau FALSE untuk pencarian tepat (exact match)!
Contoh Dasar VLOOKUP
Tabel Produk ada di F2:H20 (Kode | Nama | Harga) Ambil Nama produk berdasarkan kode di A2: =VLOOKUP(A2;$F$2:$H$20;2;0) → Cari A2 di kolom F, ambil kolom ke-2 (Nama) =VLOOKUP(A2;$F$2:$H$20;3;0) → Cari A2 di kolom F, ambil kolom ke-3 (Harga)

P003Minyak Goreng 1L18.000

⚠️

Kesalahan Umum VLOOKUP: (1) Lupa tanda $ — tabel bergeser saat AutoFill! (2) Nomor kolom salah — hitung dari kolom PERTAMA tabel. (3) Lupa 0 di parameter 4 — hasil tidak akurat!

↔️
HLOOKUP — Pencarian Data Horizontal
  • HLOOKUP = Horizontal Lookup — mencari nilai di baris pertama tabel, lalu mengambil data dari baris lain di kolom yang sama.
  • Struktur: =HLOOKUP(nilai_cari; tabel_referensi; nomor_baris; [0/FALSE])
  • Digunakan ketika data disusun secara horizontal (kategori di baris atas, data di bawahnya).
  • Lebih jarang digunakan dibanding VLOOKUP. Jika ragu, gunakan VLOOKUP saja.
Kapan Pakai HLOOKUP?
Tabel jadwal dengan hari sebagai header kolom: | Sen | Sel | Rab | Kam | Jum Kelas A | Mat | Fis | Mat | Fis | OR Kelas B | Bhs | Sen | Bhs | Sen | SB =HLOOKUP("Sel";A1:F3;2;0) → Fis (hari Selasa, Kelas A, baris ke-2)
🎯
INDEX & MATCH — Kombinasi Paling Fleksibel
  • INDEX(range; nomor_baris; [nomor_kolom]) — Mengambil nilai dari posisi tertentu dalam range.
  • MATCH(nilai_cari; range; 0) — Mencari posisi (nomor urut) suatu nilai dalam range.
  • Gabungan INDEX+MATCH lebih kuat dari VLOOKUP: bisa mencari ke KIRI, tidak bergantung nomor kolom tetap.
Contoh INDEX+MATCH
Tabel A1:C10 (Nama | NIM | Nilai) Cari nilai mahasiswa bernama "Budi": =INDEX(C1:C10;MATCH("Budi";A1:A10;0)) → MATCH mencari posisi "Budi" di kolom A → misal baris 3 → INDEX mengambil nilai dari baris 3 di kolom C
💡

Gunakan INDEX+MATCH ketika: (1) Anda perlu mencari ke kiri, (2) kolom yang dicari bisa berpindah, (3) data sangat besar. Untuk kebutuhan sederhana, VLOOKUP sudah cukup!

3

4

Rekap Nilai & Absensi Kelas XII IPS

Pertemuan 1–4 · Tingkat: Dasar
🏫 Skenario: Anda adalah wali kelas XII IPS di SMA Pembangunan, Slawi. Kepala sekolah meminta rekap akhir semester: nilai per mata pelajaran, rata-rata, grade, status kelulusan, dan rekap kehadiran 15 siswa.
  • 1
    Buat tabel: No | Nama | Ekonomi | Geografi | Sosiologi | Sejarah | Rata-rata | Grade | Status | Hadir | Alfa | Izin | % Hadir
  • 2
    Isi 12 data siswa dengan nilai 55–95 dan data kehadiran bervariasi
  • 3
    Hitung Rata-rata nilai 4 mata pelajaran per siswa menggunakan =AVERAGE()
  • 4
    Kolom Grade menggunakan =IFS(): A(≥85), B(≥75), C(≥65), D(≥55), E(<55)
  • 5
    Kolom % Hadir = Hadir ÷ (Hadir+Alfa+Izin) × 100, format Persentase
  • 6
    Kolom Status: "TUNTAS" jika rata-rata ≥70 DAN % hadir ≥80%, "TIDAK TUNTAS" jika tidak memenuhi — gunakan IF+AND
  • 7
    Buat baris ringkasan: Rata-rata kelas, Nilai tertinggi, Jumlah TUNTAS, Jumlah TIDAK TUNTAS
  • 8
    Terapkan Conditional Formatting: hijau untuk TUNTAS, merah untuk TIDAK TUNTAS
💡 Petunjuk: Rata-rata: =AVERAGE(C2:F2) | % Hadir: =J2/SUM(J2:L2) | Status: =IF(AND(G2>=70;M2>=80%);"TUNTAS";"TIDAK TUNTAS")

📋 Langkah Solusi:

1. Buat header sesuai deskripsi. Isi data baris 2–13 (12 siswa).
2. Rata-rata di G2: =AVERAGE(C2:F2) → AutoFill ke G13
3. Grade di H2: =IFS(G2>=85;"A";G2>=75;"B";G2>=65;"C";G2>=55;"D";TRUE;"E")
4. % Hadir di M2: =J2/SUM(J2:L2) → format sebagai Percentage
5. Status di N2: =IF(AND(G2>=70;M2>=80%);"TUNTAS";"TIDAK TUNTAS")
6. Jumlah TUNTAS: =COUNTIF(N2:N13;"TUNTAS")
7. Conditional Formatting: N2:N13 → Highlight "TUNTAS" hijau, "TIDAK TUNTAS" merah

Laporan Keuangan Toko Batik "Srikandi"

Pertemuan 2–5 · Tingkat: Dasar-Menengah
🧵 Skenario: Toko Batik Srikandi di Tegal meminta Anda membuat laporan keuangan bulanan. Data: penjualan harian per produk, harga, dan biaya pokok. Pemilik ingin mengetahui omzet, laba kotor, dan produk terlaris setiap bulannya.
  • 1
    Buat Sheet "Master_Produk": Kode | Nama | Kategori | Harga Jual | HPP (Harga Pokok Penjualan) — isi 8 produk
  • 2
    Buat Sheet "Data_Penjualan": Tanggal | Kode | Nama (VLOOKUP) | Kategori (VLOOKUP) | Qty | Harga (VLOOKUP) | Total | Laba Kotor — isi 25+ transaksi
  • 3
    Gunakan VLOOKUP untuk otomatis mengisi Nama, Kategori, dan Harga dari sheet Master
  • 4
    Hitung Total = Qty × Harga, dan Laba Kotor = Total − (Qty × HPP)
  • 5
    Buat ringkasan di sheet terpisah: Total Omzet, Total Laba, Omzet per Kategori (SUMIF)
  • 6
    Terapkan Conditional Formatting pada kolom Laba Kotor: hijau jika laba, merah jika rugi
  • 7
    Buat Bar Chart perbandingan omzet per kategori produk
💡 Petunjuk: VLOOKUP ke sheet Master: =VLOOKUP(B2;Master_Produk!$A:$E;3;0) | Total omzet Batik Tulis: =SUMIF(D:D;"Batik Tulis";G:G)

📋 Langkah Solusi:

1. Sheet "Master_Produk": A=Kode, B=Nama, C=Kategori, D=Harga Jual, E=HPP. Isi 8 produk.
2. Sheet "Data_Penjualan": isi kode produk manual, lalu Nama: =VLOOKUP(B2;Master_Produk!$A:$E;2;0)
3. Kategori: =VLOOKUP(B2;Master_Produk!$A:$E;3;0) | Harga: =VLOOKUP(B2;Master_Produk!$A:$E;4;0)
4. Total G2: =E2*F2 | HPP per unit: =VLOOKUP(B2;Master_Produk!$A:$E;5;0)
5. Laba Kotor H2: =G2-(E2*I2)
6. Ringkasan: Total Omzet: =SUM(G:G) | Per Kategori: =SUMIF(D:D;"Batik Tulis";G:G)
7. Bar Chart: pilih data nama kategori + omzet → Insert → Bar/Column Chart

Sistem Absensi & Penggajian Klinik Pratama

Pertemuan 4–6 · Tingkat: Menengah
🏥 Skenario: Klinik Pratama Slawi memiliki 20 karyawan. Setiap bulan HRD membuat rekap absensi dan menghitung gaji bersih termasuk tunjangan dan potongan. Anda diminta membangun sistem otomatis berbasis Excel.
  • 1
    Sheet "Master_Karyawan": ID | Nama | Jabatan | Departemen | Gaji Pokok | Tunjangan Jabatan — isi 15 karyawan
  • 2
    Sheet "Absensi_Jan": ID | Hadir | Lembur (jam) | Alfa | Cuti
  • 3
    Gunakan VLOOKUP di sheet Absensi untuk mengambil Nama, Jabatan, dan Gaji dari Master
  • 4
    Hitung Tunjangan Lembur: Rp 25.000 × Jam Lembur
  • 5
    Hitung Potongan Alfa: (Gaji Pokok ÷ 22) × Jumlah Alfa
  • 6
    Hitung Tunjangan Kehadiran dengan IF bersarang: Alfa=0→Rp300.000; Alfa≤2→Rp150.000; Alfa>2→Rp0
  • 7
    Hitung Gaji Bersih = Gaji Pokok + Tunjangan Jabatan + Tunjangan Lembur + Tunjangan Kehadiran − Potongan Alfa
  • 8
    Buat Pivot Table: Total Gaji Bersih per Departemen + Grafik Batang
💡 Petunjuk: T.Kehadiran: =IF(D2=0;300000;IF(D2<=2;150000;0)) | Potongan Alfa: =(GajiPokok/22)*D2 | Gaji Bersih: =E+F+G+H-I (sesuaikan kolom)

📋 Langkah Solusi:

1. Sheet Master: A=ID, B=Nama, C=Jabatan, D=Departemen, E=Gaji Pokok, F=Tunjangan Jabatan
2. Sheet Absensi: isi ID di A. Nama: =VLOOKUP(A2;Master!$A:$F;2;0)
3. Gaji Pokok: =VLOOKUP(A2;Master!$A:$F;5;0) | Tunjangan Jabatan: =VLOOKUP(A2;Master!$A:$F;6;0)
4. Tunjangan Lembur: =C2*25000 (C2=jam lembur)
5. Potongan Alfa: =(H2/22)*D2 (H2=gaji pokok hasil VLOOKUP, D2=alfa)
6. Tunjangan Kehadiran: =IF(D2=0;300000;IF(D2<=2;150000;0))
7. Gaji Bersih: jumlahkan semua komponen, kurangi potongan
8. Pivot Table: Rows=Departemen, Values=Gaji Bersih (Sum)

🎓Kasus 5

Sistem Informasi Akademik Prodi Manajemen

Pertemuan 1–8 · Tingkat: Lanjut (Proyek Akhir)
🎓 Skenario: Program Studi Manajemen Universitas Bhamada Slawi meminta Anda membangun Sistem Informasi Akademik berbasis Excel untuk satu angkatan (20 mahasiswa, 6 mata kuliah). Sistem harus menghitung IPK, menentukan predikat, dan menyajikan dashboard laporan.
  • 1
    Sheet "Master_MK": Kode MK | Nama MK | SKS | Dosen | Jenis (Wajib/Pilihan) — isi 6 mata kuliah
  • 2
    Sheet "Master_Mhs": NIM | Nama | Angkatan | Kelas — isi 20 mahasiswa
  • 3
    Sheet "Nilai": NIM | Kode MK | Nilai Angka | Nilai Huruf (IFS) | Bobot (IFS) | SKS (VLOOKUP) | Poin — isi 20×6=120 baris
  • 4
    Bobot Nilai: A=4, B=3, C=2, D=1, E=0 menggunakan IFS(); Poin per MK = Bobot × SKS
  • 5
    Sheet "Rekap_IPK": NIM | Nama (VLOOKUP) | Total SKS | Total Poin | IPK | Predikat | Status Akademik
  • 6
    IPK = Total Poin ÷ Total SKS; Predikat: Cum Laude(≥3.75), Sangat Memuaskan(≥3.5), Memuaskan(≥3.0), Cukup(<3.0)
  • 7
    Sheet "Dashboard": rata-rata IPK angkatan, distribusi predikat (Pie Chart), perbandingan rata-rata nilai per MK (Bar Chart)
  • 8
    Proteksi sheet "Nilai" dan "Master_MK"; buat sheet "Cetak" yang siap dicetak sebagai transkrip nilai
💡 Petunjuk: IPK: =SUMIF(Nilai!B:B;A2;Nilai!G:G)/SUMIF(Nilai!B:B;A2;Nilai!F:F) | Predikat: =IFS(E2>=3.75;"Cum Laude";E2>=3.5;"Sangat Memuaskan";E2>=3.0;"Memuaskan";TRUE;"Cukup")

📋 Langkah Solusi:

1. Isi semua sheet Master terlebih dahulu (MK dan Mahasiswa).
2. Sheet Nilai: isi 20×6=120 baris. NIM dan Kode MK sebagai identifier.
3. Nilai Huruf D2: =IFS(C2>=85;"A";C2>=75;"B";C2>=65;"C";C2>=55;"D";TRUE;"E")
4. Bobot E2: =IFS(D2="A";4;D2="B";3;D2="C";2;D2="D";1;TRUE;0)
5. SKS F2: =VLOOKUP(B2;Master_MK!$A:$C;3;0)
6. Poin G2: =E2*F2 (Bobot × SKS)
7. IPK di Rekap: =SUMIF(Nilai!B:B;A2;Nilai!G:G)/SUMIF(Nilai!B:B;A2;Nilai!F:F)
8. Predikat: =IFS(E2>=3.75;"Cum Laude";E2>=3.5;"Sangat Memuaskan";E2>=3.0;"Memuaskan";TRUE;"Cukup")
9. Dashboard: Pivot Table rata-rata nilai per MK, Pie Chart distribusi predikat
10. Protect sheet Nilai: Review → Protect Sheet → set password
